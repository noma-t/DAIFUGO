# 大富豪（セルフホスト版）

身内で集まって遊ぶための、ブラウザで動く大富豪です。
自分のPCでサーバーを起動し、ルームコードを共有するだけで遊べます。足りない席はAI（Lv1〜Lv5）が埋めます。

## 必要なもの

- [Node.js](https://nodejs.org/) 16 以上（LTS版を推奨）
- 追加のパッケージは不要です（`npm install` も不要）

## 起動方法

| OS | 操作 |
| --- | --- |
| Windows | `start.bat` をダブルクリック |
| macOS | `start.command` をダブルクリック |
| Linux | `./start.sh` を実行 |

起動するとブラウザが自動で開きます（開かない場合は `http://localhost:3000/` を開いてください）。
終了するときは、黒いウィンドウを閉じるか `Ctrl + C` を押します。

## 遊び方

1. なまえを入れて「ルームを作る」
2. 表示されたルームコード（または招待URL）を仲間に共有
3. 仲間は「ルームコードで参加」から入室
4. ルームトップで席数（3〜5人）、空き席のAIの強さ、ルール、持ち時間を決めて「ゲーム開始」
5. 全員の順位が決まるとリザルト。ホストが「もう一回」か「終了」を選ぶ

カードはクリックで選択／解除し、卓へドラッグ＆ドロップするか「出す」ボタンで出します。

## 友だちと遊ぶには

- **同じネットワーク（LAN）内**：サーバーのウィンドウとルームトップに表示される `http://192.168.x.x:3000/` 形式のURLを共有してください。
  Windowsでは初回起動時にファイアウォールの確認が出るので「アクセスを許可する」を選んでください。
- **離れた場所の友だち**：ルーターのポート開放、またはVPN（Tailscale など）で同じネットワークに入ってもらう必要があります。

ポート番号を変えたいときは、環境変数 `PORT` か `--port` で指定できます（例：`node server/server.js --port 8080`）。使用中のときは自動で次の番号を試します。

## ルールについての補足

企画書で決まっていない細かな点は、次のように実装しています。

- 1ゲーム目は ♦3 を持っている人から。2ゲーム目以降は大貧民から
- カード交換：下位は最も強いカードを自動で渡し、上位は渡すカードを選びます
- 一度パスしたら、場が流れるまで出せません
- 階段の強さは一番弱いカードで比べます（同じ枚数のみ）
- スート縛り：直前と同じスートの組が続いたら発動。数字縛り：直前のちょうど1つ上の数字が続いたら発動
- スペ3返しのあとは場が流れます
- 5飛び：出した5の枚数分だけ飛ばします
- 7渡し・10捨て：出した枚数分まで選べます（0枚も可）
- 上がり禁止：禁止カードを含む手では上がれません。親でそのカードしか残っていない場合は出せますが「反則上がり」で最下位になります
- 都落ち：大富豪以外が1位で上がった時点で、前回の大富豪は最下位になります
- クイーンボンバーで自分以外の手札がなくなった場合は、そのプレイヤーは上がりになります
- ゲーム中に切断したプレイヤーの席は AI（Lv3）が代わりに打ち、再接続すると操作が戻ります

## AIの強さ

| Lv | 名称 | 振る舞い |
| --- | --- | --- |
| 1 | ランダム | 出せる手から無作為に選ぶ |
| 2 | 素直 | 弱いカードから順に出す |
| 3 | 標準 | ペアや階段を崩さず、強いカードを温存する |
| 4 | 上級 | 出たカードを記憶し、返されない手・革命・8切りを狙う |
| 5 | 最強 | 見えていないカードから相手の手札を推測し、先の展開をシミュレーションして選ぶ |

## 構成

```
start.bat / start.command / start.sh   起動用
server/server.js   HTTPサーバー（ルーム管理・進行・持ち時間）
server/ai.js       AI
shared/engine.js   ルールエンジン（サーバーとブラウザで共用）
public/            画面（HTML / CSS / JS）
```
